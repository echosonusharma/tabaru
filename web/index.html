Features

Everything tabs should be

Built for the kind of person who has 87 tabs open and a strong opinion about it.

Primary

Fuzzy tab search

One overlay searches every open tab, every window, every recently closed session. Sub-millisecond match with character-rank scoring.

Chromium

Auto tab groups

Define URL pattern rules. Matching tabs auto-group with title, color, and collapse state. Set it once.

github.com github.com figma.com figma.com localhost
Commands

Bookmark & web search

Type !b query to fuzzy-search bookmarks by folder. Type !s query for instant web search.

New tab

New tab that earns its keep

Clock, greeting, live weather, quick-access links, and wallpaper modes - solid, gradient, or random photo.

Sessions

Closed tab recovery

Browse recently closed tabs and entire windows from the same search overlay.

Privacy

Zero telemetry

No analytics, no tracking, no remote backend. Browsing data stays in the browser.

Keyboard

All the keys, none of the mouse

Defaults shown. Remap any of them via your browser's extension shortcut settings.
